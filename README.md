# T&S SHEQ Consultants Recruitment ATS Extension

GitHub-ready custom layer for OpenCATS 0.10.x.

Features:
- Recruitment ATS workflow
- Client/company management fields
- Vacancy and placement tracking
- Candidate references
- CV parsing adapter
- Client CV redaction
- POPIA consent/disclosure fields
- Audit log schema

This is an extension/custom layer and does not replace OpenCATS core.
