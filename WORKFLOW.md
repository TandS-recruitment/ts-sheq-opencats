# T&S SHEQ Recruitment Workflow

Candidate: New Candidate -> Screening -> Vetted -> Shortlisted -> Assessment -> Interview -> Submitted to Client -> Client Interview -> Selected -> Placed / Rejected

Client: Prospect -> Contacted -> Proposal Sent -> Agreement Signed -> Vacancy Received -> Candidates Submitted -> Placement -> Invoice -> Paid

CV: Upload -> Validate -> Extract text -> Parse -> Candidate profile -> Recruiter review -> POPIA consent check -> Redact -> Client submission

Do not disclose an original CV where a redacted CV is required by the recruitment process or candidate permissions.
